Objective
Perform Data Cleaning and Preprocessing on the Titanic Dataset.

Tools and Libraries Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Dataset
Titanic Dataset containing passenger details such as:

Age
Gender
Fare
Passenger Class
Survival Status
Steps Performed
Loaded the dataset using Pandas
Checked missing/null values
Filled missing values using median and mode
Removed unnecessary columns
Encoded categorical features
Standardized numerical features
Detected outliers using Boxplot
Removed outliers using IQR method
Saved cleaned dataset

Cleaned Titanic Dataset generated successfully
Outliers detected and removed
Visualization graphs created
