# AI & ML Internship Task 1

## Objective

Perform Data Cleaning and Preprocessing on the Titanic Dataset.

---

## Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

## Dataset

Titanic Dataset containing passenger details such as:

* Age
* Gender
* Fare
* Passenger Class
* Survival Status

---

## Steps Performed

1. Loaded the dataset using Pandas
2. Checked missing/null values
3. Filled missing values using median and mode
4. Removed unnecessary columns
5. Encoded categorical features
6. Standardized numerical features
7. Detected outliers using Boxplot
8. Removed outliers using IQR method
9. Saved cleaned dataset

---

## Output

* Cleaned Titanic Dataset generated successfully
* Outliers detected and removed
* Visualization graphs created
